# ADR 001 — Estratégia de Chaves Primárias

**Status:** Aceito

## Contexto

O sistema utiliza PostgreSQL como banco de dados relacional centralizado.

## Decisão

Utilizar `BIGINT GENERATED BY DEFAULT AS IDENTITY` como chave primária das tabelas.

## Justificativa

A estratégia oferece geração automática de identificadores, simplicidade de implementação e adequação ao modelo relacional do projeto. UUID não apresenta benefício relevante para os requisitos atuais.

## Consequências

* Identificadores numéricos gerados pelo banco.
* Menor complexidade de implementação.
* IDs sequenciais não devem ser considerados um mecanismo de segurança.
